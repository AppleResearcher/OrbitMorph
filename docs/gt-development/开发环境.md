# OrbitMorph 本地开发环境

## 主机与位置
- 主节点：AgentDock-Mini；Mac mini M1、macOS 26.7、arm64。
- 源码：/Users/gt/AgentLibrary/projects/OrbitMorph
- 个人 Fork：https://github.com/AppleResearcher/OrbitMorph
- 原作者：https://github.com/samni728/OrbitMorph
- App：dist/OrbitMorph.app；DMG：dist/OrbitMorph.dmg；两者不纳入 Git。
- 仓库局部 Git 作者：AppleResearcher + GitHub noreply 地址；保留全局 Git 配置。

## 常用命令
从源码目录运行 git status -sb、git fetch origin、git fetch upstream、swift build、swift test、scripts/build-app.sh、open dist/OrbitMorph.app。

## 使用方法
首次打开应用可观看教程；按住 Shift 并拖动 Finder 文件到格式转盘，Option+Shift 使用工具转盘。输出默认在源文件旁。应使用可丢弃的测试文件，避免在验证前使用重要原件。

## 工具依赖
Swift 6、macOS 14+、Apple Silicon。系统提供 ImageIO、PDFKit、Vision、textutil 等处理能力；FFmpeg/ffprobe、ImageMagick、Pandoc、7-Zip、Ghostscript、LibreOffice、Calibre 扩展路线。第三方工具不随应用打包。

本机 xcode-select 可能指向 Command Line Tools；必要时优先使用已有 Xcode.app 的 DEVELOPER_DIR，不轻易改动系统全局开发工具设置。

## 实际体验
代码构建通过不等于真实 Finder 拖拽通过。还需观察进程、权限弹窗、多屏触发、输出文件质量。详见 测试与验收.md。
