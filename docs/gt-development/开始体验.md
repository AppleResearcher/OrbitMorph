# OrbitMorph 在 Mac mini 上首次体验

## 唯一未完成的系统操作：Xcode 首次许可

开发环境检测到完整 Xcode 26.2 已安装，但这台 Mac mini 上尚未完成 Xcode 协议确认。用户需在 Mac mini 图形桌面打开 Xcode，阅读许可并自行选择是否同意，完成首次设置。

也可在 Mac mini 自己的终端输入以下命令阅读协议并按提示确认：

    sudo xcodebuild -license

涉及管理员密码及软件许可的确认必须由用户本人完成，不应把密码交给 AI。完成后关闭 Xcode 可继续。

## 一键编译、测试并打开 App

在 Mac mini 终端执行：

    cd ~/AgentLibrary/projects/OrbitMorph
    ./scripts/gt-first-run.sh

该脚本使用完整 Xcode 构建原版、运行 Swift 测试、生成 dist/OrbitMorph.app，并尝试打开 App；如果 Xcode 初始化未完成，会清楚提示原因。原项目的业务源码保持不变。

## Finder 手动体验

1. 首次启动可在中文引导中查看手势教程。
2. 在 Finder 找一个可以丢弃的 PNG/JPG 或 MP4 复制文件。
3. 按住 Shift 并开始拖动文件，转盘出现后指向目标格式松开。
4. 按住 Option+Shift 并拖动文件可尝试工具转盘。
5. 检查产物是否生成、内容可正常读取、原始文件是否仍在。

如果系统要求输入监控、辅助功能等权限，请阅读提示后自行决定是否授权。桌面真实拖拽是体验验收项目，自动化编译不能代替。
