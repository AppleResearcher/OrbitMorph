# OrbitMorph 个性化开发计划

更新时间：2026-10-18。当前原版 1.2.1；起始基线 bc7248197017e7e29aa55e79d536ceb1f3c1a684。

## 当前目标：原版能体验
1. 从 AppleResearcher/OrbitMorph Fork 克隆源码，关联 upstream，创建 dev，不修改 main。
2. 验证 Mac mini Swift 工具链，编译、运行测试并生成应用。
3. 仅补充必要的本地转换器；体验原版 GUI 和 Finder 拖拽。
4. 用户真实体验后再确定个性化路线；此阶段不改业务功能或视觉设计。

## 尚待评审的方向
- 拖拽转盘的唤出、取消、多屏与视觉反馈。
- 转换任务的进度、取消和失败原因。
- PDF、媒体、图片能力和转换质量。
- 多 Mac 安装、正式签名与分发。

## 工作流
upstream/main（只读）→ origin/main（稳定）→ origin/dev（集成）→ feature/* 或 fix/*（独立需求）。独立分支经测试进入 dev；集成验收后通过中文 PR 进入 main。

## 阶段出口
- A：原版源码可编译，测试记录可追溯。
- B：可在 Mac mini 打开 App，并实际确认 Finder 拖拽和真实输出。
- C：体验反馈进入需求池后，才开启相应功能分支。
